# Total: 1 (out of 2003 original GCC compile cases)

# Harvest-skipped kinds (nested functions, GNU VLS, DFP, va_arg_pack,

# === Crashes / Segfaults (0) ===
# 20011109-1.c used to crash on function pointer declarations with different
# return types; fixed by not freeing types in symtable_free/symtable_leave_scope
# (the AST expressions own their types, the symtable only borrows them).
# pr53748.c used to crash (ICE) on `x ? (V){...} : (V){...}`: the conditional
# expression's usual_arith_conv returned a shallow type copy that shared the
# vector's elem_type with the branch inputs, which were then freed — double-free
# when the expr was destroyed. Fixed by having usual_arith_conv return a clone.

# === Timeouts (0) ===
# 20151204.c used to hang at -O1: scalar_constfold / scalar_peephole called
# const_value() per operand, each scanning the whole instruction array — O(n²)
# on the ~180K instructions from `char[32753] = "A"`.  Fixed by building a
# const-value cache (value id -> immediate) once per pass.  A second hang in
# regalloc's MCS ordering was O(n²) over ~143K virtual registers; fixed with a
# bucket queue so each pick is O(1) amortized.
# pr65680.c used to hang on `struct S a[10^18][3]`: the IR unconditionally
# calloc'd init_bytes for every global, then codegen emitted it all into .data
# (tens of GB).  Fixed by passing init_bytes == NULL to codegen when the
# global has no initializer, so it goes in .bss (SHT_NOBITS).

# === Compile Rejects (1) ===
# labels-3.c uses GCC's label-as-values extension (`&&label`, `goto *p`), which
# FakeCC does not support. The other three rejects (init-1.c, pr64067.c,

# learned to materialize `&((T){...})` as an anonymous static global. pr53748.c
# was a vector-typed conditional crash; it now compiles after usual_arith_conv
